# СППР — Система поддержки принятия решений

Интерактивный цифровой двойник промысла (Газпром нефть): визуальный ассистент, схема объектов и оркестратор сценариев.

## Демо

**https://axaleiger.github.io/sppr/**

## Модули

- **Визуальный ассистент** — уровни 1–3 (домены → добыча → видеоаналитика / журнал событий)
- **Схема цифровых двойников** — интерактивная топология (изометрия + техсхема), режим «Что если», панель объекта
- **Оркестратор** — сценарии 90/30/1 день, иерархия моделей, матрица процессов

## Стек

Vite · React · TypeScript · Tailwind CSS · React Flow · Recharts · Framer Motion

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Айдентика

Цвета и характер типографики по фирменному стилю Газпром нефти (Pantone 300 / 295 / 298), акцентный energy-orange для CTA и сценариев.
